PRODUCT DESIGN SYSTEM · V1.0

NexDrive
interface kit

The Nexyra identity adapted for a working tool. Flat surfaces, square corners and strong rules carry the structure. Violet marks the one primary action on each screen, and a five-colour status set is used for lessons.

01

Logo

The Nexyra monogram leads. NEX keeps the Nexyra wordmark treatment: Medium weight, +0.105em tracking, set in ink. Drive is set in sentence case with a capital D, in brand violet #7C3AED. NEX and Drive form one word with no space.

APP ICON · MONOGRAM
Clear space. Keep a margin equal to the height of the monogram on every side.
Minimum size. 120px wide for the lockup. Below that, use the monogram or the app icon.
Never set "Drive" in caps, recolour NEX, or add a space between the two words.
